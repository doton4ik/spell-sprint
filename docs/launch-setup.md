# Настройка перед запуском (то, что делается в панелях, а не в коде)

Здесь шаги, которые я не могу сделать за вас: они в панели Supabase и Netlify. Названия кнопок могут немного
отличаться, ищите по смыслу.

## 1. Закрыть предупреждение про функцию (1 минута)

1. Supabase → проект **SpellSprint** → **SQL Editor** → **New query**.
2. Вставьте и запустите файл `database/security-hardening-2.sql`.
3. **Advisors → Security**: два предупреждения про `SECURITY DEFINER` должны исчезнуть.

Лимит отчётов об ошибках продолжит работать: триггер вызывает функцию сам, право `EXECUTE` у пользователей ему не нужно.

## 2. Защита от утёкших паролей

Supabase → **Authentication** → **Sign In / Providers** (или **Policies**) → блок **Password**:

- включите **Prevent use of leaked passwords** (проверка по базе HaveIBeenPwned);
- задайте минимальную длину пароля 8 и выше.

Если этого переключателя нет в вашем тарифе (он бывает только на платных), оставьте минимальную длину и пропустите
пункт. Это предупреждение «Leaked Password Protection Disabled» тогда останется, и это нормально.

## 3. Сброс пароля по почте

В коде всё уже есть (форма «Forgot password?», письмо, окно нового пароля). Кнопка скрыта, пока не включена настройка,
потому что встроенная почта Supabase для настоящих пользователей не подходит (очень малый лимит писем в час).

1. **Своя почта (SMTP).** Supabase → **Authentication** → **Emails** → **SMTP Settings** → включить **Custom SMTP**.
   Нужен любой почтовый сервис с отправкой по SMTP (например Resend, Brevo, Mailgun, Postmark) и подтверждённый адрес
   или домен отправителя. Введите хост, порт, имя пользователя, пароль и адрес «From». Пароль SMTP держите только в панели.
2. **Адреса.** **Authentication** → **URL Configuration**:
   - **Site URL**: адрес сайта на Netlify (например `https://ваш-сайт.netlify.app`);
   - **Redirect URLs**: тот же адрес (и `http://localhost:5173` для разработки).
3. **Включить кнопку.** Netlify → Site configuration → **Environment variables** → добавить
   `VITE_PASSWORD_RESET_EMAIL` = `on`. Затем запустить новую сборку (Deploys → Trigger deploy).
4. **Проверка.** На сайте: Settings → Sign in → «Forgot password?» → ваш адрес → письмо → ссылка → окно нового пароля →
   вход с новым паролем. Проверьте также, что письмо не попало в спам.

## 4. Контакт для вопросов о данных

Страницы `#privacy` и `#terms` показывают адрес для вопросов и удаления аккаунта. Адрес берётся из переменной, в
код он не записан. Netlify → Environment variables → `VITE_CONTACT_EMAIL` = ваш адрес. Если переменной нет, страница
пишет «the person who runs this site». Это черновик: прочитайте тексты и поправьте то, что не соответствует вашему
плану (например срок хранения данных). Я не юрист: для публичного запуска в ЕС стоит показать их специалисту.

## 5. После настройки

- Проверьте вход, регистрацию и сброс пароля на телефоне.
- Запустите `pnpm check`, затем `pnpm test:e2e` (на чистой машине, без блокировки сети).
