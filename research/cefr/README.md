# Words the library does not have yet (checked 23 October 2026)

`missing-words.csv`: content words (no determiners, pronouns, prepositions, conjunctions, modals) of the CEFR-J vocabulary list
(A1-B2) and the Octanove C1/C2 list (C1 only here) that are not in `src/data/spell-sprint-built-in-library.csv`.
A word counts as present when the same word, or the same word without -s/-es/-ed/-ing, is in the library.
Not sorted by topic or frequency: the lists have no topics. The new-words pipeline gives A1 words level A2.

Sources (downloaded 23 October 2026, from https://github.com/openlanguageprofiles/olp-en-cefrj):
