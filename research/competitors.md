# Как это сделано у других платформ (разведка, 15 октября 2026)

Собрано через веб-поиск тремя помощниками (Haiku). Лично я открыл и проверил только страницу форматов заданий Linguaskill; формат
Oxford взят из поиска и описаний университетов; всё остальное со слов отчётов помощников. Пометка «проверено» в списках ниже значит
только «помощник открыл страницу», а «не проверено» значит, что факт из сниппета или чужого сайта. Цены у разных источников расходятся,
их не используем. Цифры вроде «+3,3 % удержания» это данные самой компании Duolingo, не независимое исследование.
Идеи для нас, а не копирование: форматы и приёмы, содержание своё.

## 1. Проверка уровня (Oxford, Cambridge, EF SET и другие)

**Что у них общего**
- Адаптивные: следующий вопрос зависит от предыдущего ответа (Oxford, Cambridge Placement Test, Linguaskill, EF SET).
- Много коротких заданий, почти всё выбор из 3–4 вариантов; назад вернуться нельзя.
- Oxford, Use of English: короткий диалог с пропуском и 4 варианта; «что имеет в виду говорящий» (3 варианта, смысл может быть
  неявным); текст с пропусками, слово вписывается.
- Linguaskill, чтение: записка, этикетка, сообщение или письмо и «какое предложение ближе по смыслу» (3 варианта); одно предложение
  с пропуском; текст с пятью пропусками; текст с вписыванием слова; длинный текст с вопросами.
- EF SET: тексты по 1–12 вопросов, всего около 50 вопросов; есть быстрая версия на 15 минут (20 вопросов).
- Длительность: Oxford 30–60 минут, Cambridge Placement около 30, Linguaskill около 40 (максимум 59), EF SET 25 + 25.

**Что показывает результат**
- Linguaskill: общий уровень CEFR и уровень по каждому навыку, у каждого уровня описание «что человек умеет»; видны диапазоны баллов.
- Oxford: уровень CEFR с подуровнями и балл; в карточке результата написано, что это для распределения по группам, а не сертификат.
- EF SET: шкала 0–100 и CEFR; честная оговорка, что тест слишком грубый, чтобы мерить маленький прогресс; пересдача сертифицированного
  теста раз в 90 дней, быстрая версия без ограничений.
- Lingoda: результат это рекомендация «с какого класса начать».

**Что взять нам**
1. Формат заданий Oxford и Cambridge: сделано сегодня (диалог с пропуском, «что имеет в виду B», записка и «какое предложение
   означает то же», текст с пропусками, вписать одно слово).
2. На экране результата: фраза «что умеет человек этого уровня» и пометка «это ориентир для занятий, а не сертификат».
3. Быстрая версия (около 12 вопросов) рядом с полной, как у EF SET.
4. Остановка, когда оценка уже ясна (Cambridge, Duolingo): тест короче для тех, у кого уровень очевиден.
5. Аудирование с выбором ответа (у всех оно есть; у нас пока только диктант).
6. Совет по пересдаче: у нас уже 30 дней, добавить честную оговорку про грубость оценки (EF SET).

## 2. Словарик (личные списки слов)

- **Cambridge Dictionary +Plus** (проверено): кнопка «добавить в список» прямо в словарной статье, сохраняется выбранное значение;
  списки личные или общие; готовые списки по темам; тесты по списку (набрать слово, карточки, на слух).
- **Oxford 3000 / 5000** (частично проверено): фиксированные ядра слов с уровнями CEFR и фильтром по уровню, у слова часть речи и
  британское/американское произношение.
- **Lingvist** (проверено): стартовый тест определяет словарный запас; алгоритм сам понимает, какие слова вы уже знаете, и убирает их из
  повторений.
- **Memrise** (проверено): «начал слово» = 1 очко, «полностью выучил» = 3; экран «Мои слова» с повторением и «трудными словами»; уровни
  и этапы. Минус: критерий «выучено» нигде не описан.
- **Anki** (проверено): четыре состояния карточки (новая, учится, повторение, переучивание); «молодая» и «зрелая» граница в 21 день.
- **Quizlet** (не проверено): карточка считается освоенной после двух верных ответов подряд; много режимов (карточки, письмо, на слух,
  тест, подбор пар).
- **Reverso, Cambridge**: у сохранённого слова один пример предложения рядом с переводом.
- **Lingualeo**: официальные страницы не открылись, надёжных данных нет.

**Что взять нам**
1. Мы уже умеем: добавить слово из словаря с выбранным значением и примером (как у Cambridge и Reverso), этапы повторения (как у Anki).
2. Уровни CEFR у слов и фильтр по уровню (Oxford): это напрямую связано с переделкой библиотек (темы плюс уровень).
3. После проверки уровня отметить слова ниже вашего уровня как «уже знаю» или предложить их пропустить (Lingvist).
4. Экран «Мои слова» со счётчиками «учу / знаю» и списком «трудные» (Memrise, Anki).

## 3. Практика и мотивация

- **Duolingo** (проверено): одно короткое занятие продлевает серию, дневная цель XP считается отдельно (порог низкий; данные компании:
  удержание на 14-й день +3,3 %); «заморозка серии» (до двух) как ограниченное прощение; серия с другом (до 5 человек, оба должны
  позаниматься, +22 % завершений по данным компании).
- **Anki** (проверено): один рычаг нагрузки повторений («желаемое удержание», по умолчанию 90 %); кнопку «Снова» нужно жать честно.
- **Grammarly** (частично проверено): к каждой правке приложена причина; правки сгруппированы по типам и цветам.
- **Spelling Bee** (не проверено): подсказки по ступеням (сначала количество слов и буквы, потом сами слова).
- Платные тарифы: у Quizlet бесплатная версия ограничивает сами занятия; у Memrise бесплатное ядро повторений, платное только офлайн
  и разговорная практика. Цены источники называют по-разному.

**Что взять нам**
1. Серия засчитывается за одно короткое занятие; цель дня отдельно (у нас серия уже есть, проверить порог).
2. «Заморозка» серии с ограничением вместо «всё или ничего».
3. Причина к каждой правке и тип ошибки (у нас есть правила и «My Mistakes»); лестница подсказок уже есть.
4. Один настроечный рычаг интенсивности повторений (аналог желаемого удержания у Anki).
5. Общая серия с друзьями только по желанию.

**Чего избегать:** напоминаний, которые давят чувством вины («Duo расстроен»), серии с чистым страхом потерять, ограничений на сами
занятия в бесплатной версии, автопродления пробного периода без предупреждения.
